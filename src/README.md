Library Builder Простой проект на Java для создания книг с помощью паттерна Builder.

Программа запрашивает у пользователя данные о книге (название, автор, год и жанр), собирает объект с помощью строителя и выводит результат в консоль. Описание файлов

Book.java содержит описание книги (поля: название, автор, год выпуска, жанр) BookBuilder.java отвечает за пошаговую сборку объекта книги LibraryCatalogDirector.java содержит готовый шаблон для быстрого создания книги Main.java запускает программу и считывает ввод данных из консоли
